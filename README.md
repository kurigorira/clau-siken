# clau-siken — 才弥さん 英検3級 単語トレーニング

英検3級の単語（734語）と不規則動詞（64語）を、ブラウザで覚えるための単語テストアプリです。

## 公開ページ

### 🌐 https://kurigorira.github.io/clau-siken/

スマホ・PC・タブレットのブラウザで開くだけ。インストール不要・オフラインでも動きます。
ホーム画面に追加するとアプリのように使えます。

## できること

| メニュー | 内容 |
|---|---|
| 🎯 単語テスト | 英語を見て意味を選ぶ4択クイズ |
| 🔤 意味→英語 | 日本語を見て英語を選ぶ4択クイズ |
| 🃏 フラッシュカード | めくって覚える。「覚えた／まだ」で記録 |
| 📖 不規則動詞 | 原形→過去形→過去分詞の一覧＋変化テスト |
| 🔥 苦手な単語だけ復習 | まちがえた語だけを集めて反復 |

- 分野（動詞・名詞・形容詞・熟語 など）と出題数（10〜全部）を選べます
- 正解を2回続けると「覚えた」に。ホームで進捗（覚えた語／全734語）が見えます
- 進捗はその端末のブラウザに自動保存されます

## 単語データ

- `web/words.js` … 単語データ（英検3級リストの xlsx から生成）
- `web/index.html` … アプリ本体（単体で完結）

## 公開の仕組み

`main` ブランチへの push で GitHub Actions が `web/` を GitHub Pages に自動デプロイします
（`.github/workflows/pages.yml`）。
